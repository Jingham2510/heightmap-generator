A TUI (Terminal User Interface) that allows a user to load up previously gathered heightmaps and modify them with some preset shapes.

The user can also compare two generated maps to get the difference, from which edges of deformations are detected.

The tool can also be used to generate waypoints for a robot to follow (to hopefully create the deformation)

Lots more methods to investigate!
